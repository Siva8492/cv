# GitHub Pages setup

This folder contains a ready-to-edit static academic website.

## Files
- `academic-portfolio.html` — main website file
- `README.md` — deployment instructions

## To publish on GitHub Pages
1. Create a new GitHub repository, for example `my-academic-site`.
2. Upload `academic-portfolio.html` to the repository.
3. Rename `academic-portfolio.html` to `index.html` in GitHub, or before uploading.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root` folder, then save.
7. GitHub will publish the site at a URL like `https://yourusername.github.io/my-academic-site/`.

## What to edit first
- Replace `your.email@domain.com`
- Add your Google Scholar, ORCID, GitHub, and LinkedIn links
- Replace the placeholder publication entries
- Update the short bio and research statements with your CV language
- Add your CV PDF link once uploaded to the repository

## Recommended sections to customize from your CV
- Position title and institutional affiliation
- Education details
- Publications
- Grants / fellowships / awards
- Teaching experience
- Invited talks
- Software, databases, and repositories

## Optional improvements
- Add a profile photo in an `assets/` folder
- Add a downloadable CV button
- Add a dedicated projects section for software and databases
- Add a separate `favicon.svg`
- Add Google Scholar citation metrics if you want them displayed
